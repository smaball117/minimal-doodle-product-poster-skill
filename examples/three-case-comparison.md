# Three-Case Comparison — Original × Quick × Fidelity

这轮使用 3 张用户本人拍摄的照片进行回归测试。原图允许作为仓库内测试素材展示，用来直观看 Quick Mode 与 Fidelity Mode 的差异。

![三组实拍对比](../assets/examples/three-case-comparison.svg)

## 对比表

| Case | Original | Quick Mode | Fidelity Mode |
|---|---|---|---|
| 01 蔬菜农场 | 保留完整展览现场，最大视觉元素是巨型红番茄，同时存在粉色主角色、绿植和西兰花等多个强元素。 | 保留较多原始场景关系，将多个主体一起转译为白底微缩工作世界，信息更丰富。 | 主动放大并锁定巨型红番茄，让最大元素成为唯一第一视觉中心，其余蔬菜只保留为辅助信息。 |
| 02 米奇海鲜汤 | 一整碗深色汤底，内部有虾、玉米、丸子等多个配料，视觉最大且最有辨识度的是中央黄色米奇造型食材。 | 保留整碗食材丰富度，小人围绕不同配料工作，整体更像完整故事场景。 | 强化中央黄色米奇造型食材的面积和位置，先读到“最大核心元素”，再读到汤和配料。 |
| 03 焦糖饼干冰淇淋 | 金属碗、香草冰淇淋、焦糖酱与一块竖直焦糖饼干共同组成主体，其中饼干是最强形状锚点。 | 保留饼干、冰淇淋、焦糖酱之间的原始关系，小人分散在整个甜品周围工作。 | 进一步放大焦糖饼干，让它成为最明显的视觉锚点，同时保留冰淇淋球和焦糖质感作为第二层信息。 |

## 这轮测试得到的结论

1. **Quick Mode 更适合保留“场景故事”。** 当原图包含多个有趣元素时，它会倾向于把多个信息一起带进海报。
2. **Fidelity Mode 在明确指定 focus 后更稳定。** 本轮的 focus 是 `dominant element`，即优先突出画面中视觉面积最大或形状最强的元素。
3. **“最大元素”不等于“随意重画一个新主体”。** 仍然必须受 Subject Lock 约束，保留原始类别、材质、颜色和关键结构。
4. **小人系统整体已经趋于稳定，但仍需继续压制表情、服饰和过度卡通化。**
5. **字体依旧是当前最容易漂移的模块。** Quick Mode 中可接受轻微误差，Fidelity Mode 如强调字体，应继续使用独立 Lettering Layer。

## 下一轮建议测试

- 非食品类单品，例如护肤品、香水、鞋、包；
- 只有一个极简主体的照片，验证是否会“为了热闹而加太多小人”；
- 带包装文字的产品，验证是否会错误生成品牌文字；
- 同一原图分别测试 `subject identity`、`dominant element`、`lettering` 三种 Fidelity focus。
