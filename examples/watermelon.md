# Example: Watermelon Poster

## Input

```yaml
subject: 刚切开的冰镇西瓜
feature: 多汁、清凉、补水、带籽、夏日感
caption: 补水中
worker_count: 5
color_palette: 红、绿、白、黑色线稿
```

## Feature-to-action mapping

| Product feature | Miniature metaphor | Worker action |
|---|---|---|
| 多汁 / 补水 | 水源系统 | 用水管给西瓜“补水” |
| 西瓜籽 | 货物 | 推小车搬运西瓜籽 |
| 清凉 | 避暑区 | 坐在西瓜边缘乘凉 |
| 成熟度 | 品控检查 | 爬梯子检查果肉与成熟度 |
| 果肉饱满 | 开采 / 取样 | 用小勺挖西瓜果肉 |

## Final three-step prompt

```text
1、请设计一张极简治愈系夏日产品海报，整体气质高级、安静、有呼吸感，采用国际品牌产品广告式的大面积留白，而不是传统插画海报。

背景为纯白色，约 70%–80% 为干净留白。画面只保留一个真实摄影质感的核心主体，主体居中偏下，整体构图简洁克制。主体采用专业商业静物摄影质感，摄影棚大面积柔光，高键、低反差，材质、表面纹理和细节真实清晰，主体下方只有轻柔自然的接触阴影。

在真实摄影主体周围加入少量黑色手绘线稿。线条像黑色马克笔或签字笔随手画出，略微不规则、稚拙、松弛、有童趣，但保持简洁，不做精致插画。线稿包含微缩小人、梯子、水管、小车、勺子、云朵、波浪线和手绘箭头等少量元素。

微缩小人的动作必须围绕西瓜展开，像一群人在认真工作。每一个动作都直接表达西瓜多汁、补水、清凉、带籽和成熟度等特点，把西瓜变成一个巨大的微缩工作现场，而不是随机装饰。

2、整体风格保持克制、留白充足、真实摄影高级、安静治愈，并带有轻微幽默和微缩故事感。真实摄影主体是第一视觉重点，黑色线稿只是叙事层，不能抢过主体。

颜色只使用西瓜自身的红色、绿色、白色背景与黑色线稿，不增加额外装饰色。画面保持纯白背景、黑色单线手绘与真实摄影材质之间的强对比。

不要品牌 Logo，不要边框，不要复杂排版，不要价格标签，不要大段广告文案，不要彩色插画，不要精致矢量人物，不要 3D 卡通，不要动漫漫画感，不要复杂场景，不要多主体拼贴，不要把西瓜画成插画或塑料感 3D 模型，不要明显 AI 绘画质感。

3、主体是一块刚切开的冰镇西瓜，横向放置在画面中央偏下位置。果肉鲜红饱满，纤维和汁水纹理真实清晰，表面带有细密晶莹水珠，绿色瓜皮自然厚实，切面新鲜湿润，呈现刚从冰箱取出的清凉状态，具有真实商业食品摄影质感。

画面里有 5 个黑色单线稿微缩小人：
1. 一个小人站在西瓜左上方，拿着水管给西瓜果肉喷水，像在给西瓜补水；
2. 一个小人在西瓜下方推着小车，搬运散落的西瓜籽，把瓜籽当成货物；
3. 一个小人坐在西瓜边缘乘凉，姿态松弛，像把西瓜当作夏日避暑平台；
4. 一个小人沿着梯子爬到西瓜侧面，认真检查果肉和成熟度；
5. 一个小人站在西瓜右侧，拿着小勺正在挖取西瓜果肉，像进行取样检查。

这些动作共同形成一个围绕西瓜运转的微缩工作现场，每一个动作都与西瓜的补水、多汁、清凉、成熟和果肉特点直接相关。

画面左上方大面积空白区域，用黑色随手写字体写：补水中。旁边画一条松弛的手绘弯箭头指向西瓜。文字体量很小，不做正式字体排版。

整个画面只保留西瓜的红色、绿色、纯白背景和黑色线稿，整体清爽、安静、凉快，留白巨大，真实摄影主体高级，手绘线稿轻巧幽默。
```

## Why this example works

- 核心主体只有一个，视觉中心明确；
- “补水中”与西瓜多汁、夏日清凉形成直接关联；
- 五个小人的动作分别承担不同产品信息，没有重复；
- 线稿承担故事，摄影承担质感，两层语言没有互相打架；
- 红、绿、白、黑已经足够形成完整视觉，不需要额外颜色。
